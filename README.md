This is a code for model construction and data analysis in the research process of Francois’ langur, as well as relevant information on graphic drawing during the research process

In the naming of the note_importance folder, 1rm, 0.8rm, 0.6rm, and 0.4rm correspond to the minimum required area habitat thresholds of four species (10.59km2, 14.26km2, 22.56km2, and 46.19km2), respectively.Bio represents dynamic scenario a, and lulc represents dynamic scenario b
